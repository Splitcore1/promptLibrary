# Promptfolio

Личная библиотека промптов для генерации изображений. Светлый интерфейс, адаптивная сетка, коллекции, избранное, поиск и фильтрация моделей. Nano Banana выбрана по умолчанию.

## Готовое приложение для Windows

Откройте [последний релиз](https://github.com/Splitcore1/promptLibrary/releases/latest), скачайте архив **windows-x64.zip**, полностью распакуйте его и дважды нажмите **Start-Promptfolio.cmd**. В готовом архиве включены Node.js и зависимости; база подготавливается автоматически, приложение открывается в браузере. Окно запуска должно оставаться открытым во время работы.

Локальные промпты хранятся внутри папки приложения. Данные онлайн-версии переносятся через экспорт и импорт. Source code ZIP предназначен для разработки.

Промпты и редакции хранятся в Cloudflare D1, загруженные обложки и референсы — в R2. Авторизация предоставляется Sites / ChatGPT. Все серверные операции проверяют владельца записи. Новое приложение опубликовано с доступом только для владельца.

## Разработка

Требуется Node.js 22.13 или новее.

~~~sh
npm ci
npm run db:generate
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_fluffy_jimmy_woo.sql
npm run dev
~~~

В локальной разработке вход через /signin-with-chatgpt?return_to=/ создаёт тестовую сессию. В опубликованном приложении используется настоящая авторизация Sites. Локальные данные не попадают в публикацию.

~~~sh
npm run check
npm test
~~~

## Данные и переносимость

- Создание, редактирование, удаление и дублирование промптов.
- Обязательны название, модель, текст и загруженная обложка. Описание, параметры и негативный промпт необязательны.
- До 8 референсов, каждый файл до 10 МБ: JPG, PNG, WebP, GIF, AVIF.
- Создание, переименование, выбор цвета и удаление коллекций; промпт может входить в несколько коллекций.
- Поиск по названию, описанию, тексту, параметрам, тегам и модели.
- История изменений со восстановлением в новую редакцию; проверка конфликтующих сохранений.
- JSON-экспорт текущих данных, коллекций, изображений и истории. Импорт добавляет промпты, объединяет коллекции по названию и сохраняет редакции. Один импорт: до 100 промптов, до 100 коллекций, до 500 операций записи и 150 МБ файла; большие копии следует разделять.
- HTML-карточка для отправки другому человеку: все изображения встроены в файл, аккаунт для просмотра не требуется.
- Ссылки на карточки внутри приложения доступны только владельцу.

В разделе «Вдохновение» находятся иллюстративные примеры, они не являются сохранёнными данными пользователя. При добавлении примера требуется собственная обложка.

Удаление промпта удаляет его редакции. R2-изображения остаются, поскольку ими могут пользоваться дубликаты и предыдущие редакции других карточек. Для большого объёма данных потребуется сборка неиспользуемых изображений с проверкой всех ссылок.
