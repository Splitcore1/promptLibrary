## Promptfolio — личная библиотека промптов

### Запуск на Windows 10/11 x64

1. Скачайте **Promptfolio-v0.1.0-windows-x64.zip** из раздела **Assets** ниже.
2. Полностью распакуйте архив в обычную папку, например в «Документы».
3. Дважды нажмите **Start-Promptfolio.cmd** внутри распакованной папки.
4. Подождите запуска: библиотека автоматически откроется в браузере.

Node.js и зависимости уже включены. Устанавливать Node.js отдельно и выполнять команды npm не нужно. Оставляйте окно запуска открытым во время работы; для остановки нажмите Ctrl+C.

Кнопки **Source code (zip/tar.gz)** содержат исходники для разработки. Для простого запуска выбирайте архив **windows-x64.zip**.

### Возможности

- Карточки промптов с результатами генерации и референсами.
- Nano Banana по умолчанию, фильтры других моделей, поиск, коллекции и избранное.
- Редактирование, дублирование и восстановление предыдущих версий.
- Экспорт и импорт библиотеки с изображениями и историей.
- HTML-карточки для отправки другим людям.
- Светлый интерфейс с адаптивной версткой.

Локальная библиотека хранится внутри распакованной папки. Сохраняйте всю папку приложения; резервную копию можно скачать кнопкой «Экспорт». Для переноса данных с онлайн-версии используйте экспорт и импорт.

Конструктор промптов запланирован следующим этапом; его бриф находится в docs/constructor-brief.md.

Файл SHA256SUMS.txt содержит контрольную сумму архива.
